# Garrett Butchko - Resume

This repository contains the LaTeX source and compiled PDF for Garrett Butchko's resume.

## Files
- [`resume.tex`](resume.tex) - Primary LaTeX source file (strict black-and-white, single-page, standard TeX distribution compatible).
- [`resume.pdf`](resume.pdf) - Compiled PDF version.

## Compilation
To compile the resume to PDF:
```bash
pdflatex resume.tex
```
